# 运镜与运动呈现

先明确运动要改变什么，再选择路径、速度、器材和拍法。让每个移动镜头拥有可拍的开始、中途与结束。
下列情绪对应、时长和路径是实践综合建议；源自资料的技术事实用编号标示，不能把创作建议当作设备承诺。

## 运镜决策顺序

1. 用一句话说明动机：跟随行动、展示空间、揭示信息、改变关系或表达视点变化。
2. 先试静机位配演员调度；若信息与情绪已经完整，保留静镜头。
3. 定义起幅和落幅：人物大小、屏幕位置、前后景、焦点及可见信息。
4. 把启动和停止绑定到动作或声音，例如“手离开门把时启动”，而不是只写“缓缓”。
5. 决定是旋转、平移、升降、变焦还是转焦；不要把不同动作混为一个词。
6. 检查运动沿途的遮挡、光线、反射、焦点、声音、轴线与地面条件。
7. 再选器材，先以静态或短路径版本保底，按叙事价值安排复杂镜头。

## 动作词汇与用途

以下为术语释义与原创应用建议。改变空间位置与原地转动的效果不同；实际术语可能因剧组习惯而异，应优先把路径说清。

| 动作 | 摄影机实际发生什么 | 可尝试的叙事任务 | 必须写清 |
|---|---|---|---|
| 固定 locked-off | 机位与构图维持稳定 | 等待、观察、让表演占据注意力 | 谁进入/离开，何时切出 |
| 横摇 pan | 原地向左/右转动视轴 | 顺着视线发现另一人或空间 | 起止目标、方向、揭示时间 |
| 俯仰 tilt | 原地向上/下转动视轴 | 从证据到人物、从人到环境 | 起止高度关系、机位是否保持 |
| 推进 dolly-in | 机位向主体靠近 | 收紧关注、进入认知变化 | 路程、人物占比、终点距离 |
| 拉远 dolly-out | 机位离开主体 | 展示处境、改变观众对空间的判断 | 新露出的信息和出现时机 |
| 横移 truck | 机位横向移动 | 展示前后景视差、绕开遮挡 | 地面方向与画面运动分别描述 |
| 跟移 tracking | 与人物一起穿过空间 | 保持陪伴、展示路线 | 摄影机领先/跟后/并行、相对距离 |
| 弧线/环绕 arc/orbit | 绕对象改变观看角度 | 关系重组、逐步揭示背景 | 弧度、半径、轴线重建、落幅 |
| 升降 boom/pedestal | 改变机位高度 | 由细节到全貌、随角色起身 | 高度区间，是否同时俯仰 |
| 变焦 zoom | 改变镜头焦距 | 强调取景范围变化或观察感 | 焦距/构图起止、机位是否不动 |
| 推拉变焦 dolly zoom | 移动与变焦协同 | 制造空间认知突变 | 主体大小是否保持、运动与变焦方向 |
| 甩镜 whip pan | 快速横向转动视轴 | 动作连接、突然转移注意力 | 可剪接区间与运动方向 |
| 转焦 rack focus | 在不同距离对象间转移焦点 | 让注意力在两条信息间切换 | 前后焦点、触发点、时长 |

静止机位的光学变焦一般不提供真实平移的前后景视差；镜头呼吸、畸变及光学设计仍可能改变画面表现。几何透视与焦距的关系见 camera-and-composition.md 的 C02。
推拉变焦需要协调机位与焦距，不能只写“震撼的希区柯克镜头”就视为可执行。[C07]

## 支撑方式与预算

ASC 的器材综述区分了手持、轨道/移动底座、滑轨、电子稳定器及身体支撑稳定系统；这些工具在机动性、空间和运动特性上各有条件。[C07]

| 已有条件 | 优先尝试 | 注意事项 | 预算受限时的替代 |
|---|---|---|---|
| 三脚架/固定支点 | 稳定构图、受控摇移 | 水平、阻尼、机位与演员距离 | 让演员或道具移动 |
| 手持小设备 | 近距离跟随、反应灵活的短镜头 | 地面、呼吸抖动、观看舒适度 | 缩短路径，增加固定镜头接点 |
| 小滑轨 | 精确短距离位移 | 起止缓冲、载重与支撑、近景遮挡 | 用两个机位剪接揭示 |
| 电子稳定器 | 狭窄空间的跟随或曲线路径 | 调平、负载、步伐起伏、设备支持 | 更广松的构图与较短路线 |
| 轨道/专业移动底座 | 可重复、可控的路径 | 铺设、平整、回位、团队配合 | 静态主镜头与单次短推进 |
| 摇臂/起重系统 | 大范围高度与空间变化 | 专业操作、承重、人员隔离 | 高低两个安全固定机位接合 |

不要把电子稳定器、Steadicam、IBIS、光学防抖与后期稳定当作同一种机制。
后期稳定可能带来裁切或边缘形变，应试拍回放；不承诺它能修复失焦、遮挡或滚动快门形变。
不推荐用不合适的椅子、车辆或临时高处充当承人移动底座。

## 运镜执行卡

每个移动镜头写齐以下字段；小团队可以合并成一行，但不要遗漏动机和结束条件。

| 字段 | 写法示例 |
|---|---|
| 叙事变化 | 从“只看到老板”变成“发现身后无人工作” |
| 起幅 | 老板胸上，画面右侧，前景门框遮住背景 |
| 触发点 | 老板停下讲话并转头 |
| 机位路径 | 从门框旁横移约半步，镜头始终朝车间内 |
| 演员路径 | 老板留在标记处，只转头；背景演员保持动作约定 |
| 落幅 | 老板移到画面边缘，空工作台占主体 |
| 速度曲线 | 开始轻缓，途中匀速，信息完全露出后停止 |
| 焦点策略 | 先保住老板，揭示时转向工作台；不可可靠转焦则拆镜 |
| 时间 | 可用段暂定 5 秒；另录动作前后余量，具体随剪辑调整 |
| 约束/备选 | 不穿过墙体；空间不足则用老板反应接工作台固定全景 |

“向右”必须注明相对谁：摄影机向场地东侧移动，与“主体向画面左侧移动”并不等价。
长镜头增加检查点：每个拍点的信息变化、演员/焦点标记、灯具与收音隐藏、可补拍的插入镜头。
除非用户要求与条件允许，不把一镜到底作为默认优选。

## 帧率快门与运动伪影

单帧曝光时间近似为 `t = 快门角度 ÷ (360 × 拍摄帧率)`。例如 25 fps、180° 对应 1/50 秒；相同帧率下减小角度会减少运动模糊并减少曝光时间。180° 是常见起点，不是普遍正确值。[C06]
拍摄帧率、时间线帧率和播放速度分别记录；24、25、30 或更高帧率的选择应服务交付与动作表达。
在时间线按帧解释的理想情况下，50 fps 素材以 25 fps 播放为半速；按实时播放则不会自动慢动作。

| 观察到的问题 | 先区分 | 测试办法 |
|---|---|---|
| 横摇像跳格 | 运动采样/播放节奏还是曝光模糊 | 实际输出设备播放，比较较慢横摇与原速 |
| 竖线倾斜或画面软扭 | 滚动快门形变还是镜头畸变 | 同机位做静态与移动对照；避免只改快门便宣称修复 |
| 灯光条纹或亮度跳动 | 光源调制与拍摄同步问题 | 用目标帧率、快门和灯光调光状态试录；转布光模块排查 |
| 动作过糊 | 快门、主体速度与机位速度 | 按创意需要试短曝光，同时补偿曝光损失 |
| 动作太碎太硬 | 快门过短或画面位移过大 | 对照常见快门起点、减慢运动，检查播放链路 |

ARRI 白皮书指出，即使 180° 也可能在快速横摇时出现明显离散运动感；因此不规定一个适用于全部焦段、屏幕和内容的“安全摇摄秒数”。[C06]
先检查交付格式、光源及屏幕，再给精确快门建议；在未知 LED/显示屏环境中不承诺某个快门绝对无频闪。
给 AI 视频的光学与运镜词语应解释为意图；只有接口实际支持时才把帧率、快门或轨迹当作硬参数。

## 三种可拍案例

以下均为原创方案，距离和时间是排练示例，不能误称行业标准或某影片的实际拍法。

### A. 怀疑加深：短推进

中景开始；人物发现异常后停止说话，摄影机在约 4 秒内推进约半米，落在更紧的胸上。
机位高度保持；重点是表演被看见，不强求某个焦段。测试前后焦点及近处是否挡光。
失去焦点或空间过小：改固定近景，从停顿前切入，保留反应持续时间。

### B. 交代危险位置：横移揭示

以门框遮住部分背景，人物留在前景；随着人物看向门后，短横移让危险对象进入画面。
先按落幅摆好危险对象，再反推起幅及门框遮挡；不要在镜头开始时提前泄露。
无法安全横移：用视线镜头接目标特写，声音提前带入。

### C. 角色退出权力中心：拉远

从人物近景拉到能看到空房间的中远景；人物保持原地，让环境关系改变。
把重要物件布置在拉远后才可读的位置；检查整个路径曝光、反射和焦点变化。
小房间没有退距：从近景切到门外固定全景，通过空间对比完成同一信息变化。

## 排障与验收

- 静音回看：观众是否知道运动前后新增了什么？不知道则重写动机或缩短镜头。
- 检查起幅与落幅是否都能独立停留，避免运动停在无信息的位置。
- 检查焦点、遮挡和亮度是否在中途失控；不能只看首尾帧。
- 把前镜尾帧与后镜首帧并列，核对人物方向、视线、动作和运动能量。
- 让每个高复杂度镜头有一个不依赖特殊器材的保底版本。
- 倒退、绕障碍及穿越狭窄空间时安排明确的保护与引导人员；先清理路径，再排练。

ASC 对 dolly grip 的说明特别强调移动平台稳定与摄影操作者的保护引导；复杂移动的安全职责必须明确，而非默认由摄影师边看监视器边兼顾。[C08]
