## 证据与剪辑目标

本文件中的工作流、优先级、模板和练习为原创实践综合。带 [Pxx] 的短段仅归纳对应来源的有限结论；不要把某个设备操作或历史教材中的产品状态当作当前行业规范。

剪辑通过选择镜头、顺序和持续时间塑造信息与意义，能压缩或延展观众感知的时间。Academy 的教材用重排相同画面说明顺序如何改变理解，并强调剪辑只能使用实际拍到的材料。[P06]

先写目标剪辑骨架，再列拍摄镜头：观众进入场景 → 获得必要信息 → 行动或反应改变局面 → 形成新理解。短片未必需要完整三幕，但需要知道每段在做什么。

先做能看懂的工作剪，再调整节奏和风格。不要用音乐、频繁转场和调色遮盖缺失的因果。

## 剪点和素材需求

| 剪辑动作 | 叙事用途 | 拍摄前必须留下 | 失败信号 |
|---|---|---|---|
| 直接切 | 改变注意力、时间或空间 | 下一镜有明确新信息 | 每镜都重复上一镜 |
| 动作匹配 | 跨景别延续动作 | 双方完整动作、方向和重心 | 手位置跳变，动作重复一遍 |
| 视线匹配 | 建立“看见—对象—反应” | 可对应的目光、对象机位和反馈 | 观众误认看向何处 |
| 反应镜头 | 让观众理解听者或后果 | 反应前后状态与眼神变化 | 只拍无意义点头 |
| 插入镜头/切出镜头 | 提供证据、改变时间、留剪辑弹性 | 道具状态与所在空间的对应 | 道具突然出现或暗示错误因果 |
| 图形/动作呼应 | 连接概念、时间或地点 | 可比的形状、动作阶段、构图位置 | 为转场硬改剧情 |
| 跳切 | 省略时间、制造断裂或表达主观状态 | 让观众能辨认保留的信息 | 被误看成连续性失误 |
| 平行剪辑 | 对照或交替发展事件 | 时间关系、空间锚点、各线的阶段 | 无依据地暗示同步发生 |
| 叠化/淡出 | 表示延续、过渡或主观体验 | 足够头尾余量和相容画面 | 多一层重影却无叙事用途 |

J-cut 让后一个镜头的声音先出现；L-cut 让前一个镜头的声音延续到后一个画面。它们都把声、画剪点错开，可用于预示新空间或保留听者反应。[P07]

原创应用：A 说“你不用回答”时，把画面先切到 B 的沉默，而让 A 的声音继续；此处使用 L-cut。另一个场景的机器声先进入当前空走廊画面，是 J-cut 的候选。明确标记声音属于哪个空间，避免把声音桥误写成画面时长叠加。

节奏不等于切镜速度。先找信息何时可读、表演何时变化，再决定切点。比较稍早、按原计划、稍晚三个版本；选择最能传递意图的版本，别机械追随每个音乐鼓点。

对高速动作逐镜检查方向、接触点和结果，对静态情绪场景检查眼神、呼吸与停顿。连续性服务观看体验，物理位置完全一致也可能因情绪断裂而不顺畅。

## 声音叙事与同期录音

按“对白/旁白、环境、动作/拟音、音乐”分层设计，标注画内、画外或主观声音。安排每个节拍最重要的声音，不让所有层同时争夺注意力。

Academy 的声音教材说明现场可补录非同步声音供后期使用，ADR 用于重录对白，拟音可对画面补充动作声；混音通过层次、强弱和听觉视点引导关注。安静感也可以由细小声音呈现，未必需要绝对静音。[P09]

把关键声写进镜头表：声音来自哪里、先于还是后于画面、是否触发人物反应、拍摄还是后期制作。悬疑中先听见但看不见的声源必须在故事上可解释；广告中的功能声不要夸大真实功能。

Shure 指南强调现场勘查、尽量靠近声源、按实际最大音量设电平、使用耳机监听实际录制链路，并预先评估风、空调、反射和设备噪声。重要且不能重来的录音可考虑独立备份；多支麦克风并不自动更好。[P08]

### 同期录音的原创执行卡

| 项目 | 执行动作 | 通过标准 |
|---|---|---|
| 环境 | 在预计拍摄时段听交通、设备、邻近活动 | 关键台词可录；噪声时段有替代计划 |
| 麦克风选择 | 根据景别、走位、衣物、环境决定吊杆、领夹或可见话筒 | 能获得可懂对白，不妨碍表演和画面 |
| 距离与方向 | 在不入画、不制造阴影的范围内靠近；试听偏轴变化 | 声音清楚、音色可接受，角色转头仍有覆盖 |
| 领夹 | 排练转头、抱臂、走路等动作 | 无明显衣物摩擦、触碰和断续 |
| 录音设置 | 确认采样率、位深、输入模式、供电及通道命名适配后期 | 记录设置；不用未经核实的机型通用预设 |
| 电平 | 用真正表演音量测试并留余量 | 不削波；微弱对白不被底噪淹没 |
| 监听 | 从录音端监听；试录后回放 | 实际文件有正确通道，非仅输入表在动 |
| 同步 | 相机和录音机同录清晰拍板或可识别同步事件 | 后期可对齐，长录制检查漂移 |
| 环境底声 | 人员和设备维持拍摄状态，单独录一段连续底声 | 能填补剪辑间隙；长度随场景决定 |
| 关键声 | 分别补录门、脚步、道具与重要画外声 | 有可编辑的清晰版本与空间说明 |

不要把“32-bit float”“双通道”或降噪软件当成免测试保证：话筒、发射器、前级、布置和环境仍可能造成失真或不可用声音。具体设备能力查当时官方手册。

若对白录坏，先判断是局部噪声、整段混响、衣物摩擦、无线丢包还是削波，再在补拍、wild line、ADR 与有限修复之间选择；不能承诺后期必然救回。

## 从镜头清单到拍摄顺序

成片镜头顺序与实拍拍摄顺序分别输出。摄影机先后不是故事先后；调度优化应保住光线时机、演员状态与剪辑所需内容。

采用以下排序逻辑，发生冲突时解释取舍：不可延后的天气/自然光或场地限制 → 难重复事件 → 演员关键表演 → P0 因果镜头 → 同灯位/同机位可合并内容 → P1 反应与补充 → P2 装饰。

不要默认先把全景拍到完美再拍近景。也不要为减少一次转灯把情绪高潮放在演员疲惫之后。记录每次改序造成的服装、道具、光线与表演连续性代价。

| 拍摄序号 | 镜号组 | 灯位/机位组 | 角色与道具状态 | 预计准备/拍摄/复位 | 必须先完成 | 删除/替代方案 |
|---|---|---|---|---|---|---|
| 1 | S01、S06 | 关系镜头组 | 开场与结尾分别拍照记录 | 给区间估算，现场计时修正 | 确认两种表演状态 | 结尾可保留静态关系镜头 |
| 2 | S02、S05 | A 侧机位组 | 钥匙在手/已放桌上分别标记 | 包含收音、焦点和彩排 | A 的情绪转折 | 推近改固定近景 |
| 3 | S03、S04 | B 侧机位组 | 钥匙位置、推回距离一致 | 包含表演前后余量 | 反应与关键台词 | 删装饰特写，保留因果 |
| 4 | 补充声/细节 | 维持空间和道具状态 | 房间、钥匙、门等分别说明 | 随剩余时间调整 | 确认已有可剪主干 | P0 缺失优先补拍 |

上表为“归还钥匙”示例的原创拍摄排序，不是工时承诺；具体排程需灯光变化、演员和场地信息。

估算现场时间时分别列：搭设、排练、灯光/收音/焦点调整、每条拍摄、复位、转场、必要休息和素材核验。不用“片长 60 秒，所以半小时拍完”的换算。

当资源不足，给三层方案：保留故事的最低方案、建议方案、增加资源后的增强方案。必须指出削减后失去的具体效果，不只给装备清单。

## 连续性与现场检查

用一张连续性表追踪同场镜头：人物站位/身体方向、视线、使用哪只手、道具位置与状态、服装/头发、行动节奏、光源方向、环境声和表演强度。

每次开拍前只查会影响这一镜的项目，避免把长清单变成机械仪式：

1. 导演确认本条意图、演员动作与结尾保持。
2. 摄影/跟焦确认画幅、焦点范围、运动路径与构图边界。
3. 灯光确认人物全程光区、反光、阴影与实际景别。
4. 录音确认监听、电平、衣物和机位变化带来的问题。
5. 场记确认镜号、条次、状态变化及与前后镜头的接法。
6. 开始前留稳定状态，动作完成后保留可剪余量；具体长短由动作和转场决定。

回看重点：关键表演是否成立、焦点是否可用、动作是否完整、声音是否真的录到、反光/麦杆/设备是否入画；不能只看“画面好不好看”。

场记条目可用：`场次-镜号-条次｜可用段｜表演选择｜画面/声音问题｜连续性变化｜需补项`。不要只有“好/不好”。

危险动作、车辆、临边、吊装、强电、火烟、水下等让相应专业人员设计与执行。该模块仅帮助镜头和部门协作，不以分镜替代现场风险评估。

## 后期和交付复核

- 入库核验：保留原素材，确认文件可打开、时长正常、音轨正确；镜号和条次能追溯到记录。素材至少有经核验的独立副本后才考虑释放原介质。
- 工作剪：先验证因果、空间、人物关系和对白完整，再处理节奏、风格与精细技术。
- 声音剪辑：对齐同步，检查切口、环境底声、音色突变与可懂度；音乐与效果让位于该节拍的主信息。
- 调色衔接：先统一输入和监看逻辑，再匹配同场镜头；具体色彩流程见曝光/色彩模块。
- 字幕与画幅：在实际观看尺寸检查字的可读性、遮挡和持续时间；横竖版本分别检查手、脸、证据和落版。
- 输出：按实际交付对象确定容器、编码、分辨率、帧率、色彩与声音要求，不写一个对所有平台有效的固定值。
- 成片核对：片头、片尾、叠化、停帧和落版纳入总片长；重新测量而非沿用分镜表估计。
- 观看复核：完整播放一次；同时在目标设备检查暗部、声音、字幕和自动裁切。以用户目标判断是否完成。

不把“画外声”与“非叙事音乐”等同：前者只是当前画面外的声音，也可能来自故事空间内。声音来自哪里与观众是否看到来源，是两条不同的判断轴。

## 原创练习与问题诊断

练习采用现有设备即可，每次只改变一个变量，并保存判断依据；不要求额外购买。

| 练习 | 任务 | 对比方式 | 评价问题 |
|---|---|---|---|
| 六镜头无对白 | 用钥匙、杯子等拍出“想拿—犹豫—放弃” | 删除任一镜再看 | 因果是否还能理解 |
| 同素材两种剪法 | 同一对话剪出亲近和疏离两个版本 | 改切点、反应与声音保留 | 意义改变来自哪个具体选择 |
| 声音改变空间 | 同一静止画面配两套合理画外声 | 仅换声源和远近 | 观众对场外空间的想象如何变化 |
| 轴线实验 | 拍普通同侧、可见跨轴、突切越轴三版 | 保持台词和动作相同 | 方向改变是可理解还是无意混乱 |
| 竖屏重构 | 同一动作直接竖拍并由横版裁切 | 用手机尺寸回看 | 重要动作和人物关系是否丢失 |

| 症状 | 先排查 | 最小修正 |
|---|---|---|
| 画面漂亮但故事难懂 | 是否缺少动作目标、证据或反应 | 补因果镜头或重排信息 |
| 台词塞不进时长 | 实读、停顿、并行/串行动作 | 减词、改结构、调整时间分配 |
| 对话像轮流念稿 | 是否缺少听者与关系变化 | 使用有内容的反应；让动作推动节拍 |
| 反打方向乱 | 视线对象、轴线与站位变化 | 重新建立空间或调整选镜 |
| 声音忽远忽近 | 麦距、音色、环境底声变化 | 选一致素材、补底声，必要时补录 |
| 节奏拖或太碎 | 同一信息重复、过早切断反应 | 删除重复或给关键反应留时间 |
| 现场拍不完 | P0 是否清楚，是否过多换机换灯 | 合并设置，删 P2，保留可剪骨架 |
