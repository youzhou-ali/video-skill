## 适配原则

先完成电影设计，再转换为指定工具能表达的输入。以下流程是原创工程与创作建议，不保证任何模型精确复现物理摄影。

不同提供方的提示策略存在差异：Runway Gen-4 官方强调简洁、正向表达和逐步增加运动信息；Google 的 Veo 指南允许较详细的场景、人物、动作和声音描述。不能把一家指南写成所有模型的硬规则。[A01][A03]

毫米焦距、T值、色温、厘米和秒数可以辅助表达意图，但生成模型未必提供相应物理控制。优先描述可见结果；例如「人物半身大小基本保持，背景在推进中明显展开」。是否支持首尾帧、参考角色、多镜头、音频、负面输入、种子、时长和分辨率，以实际模型版本和当前接口文档为准。[A04]

不要默认用户使用 Runway、Veo、Seedance 或其他工具。未给模型时产出通用镜头卡，将模型专属配置列为待核实项。

## 分两层表达

**创作与验收层**保留完整目标：镜头动机、角色状态、空间关系、光线、剪辑点、不能改变的道具和连续性。
**模型输入层**只保留这次生成最需要控制的视觉与动作信息，按该模型的格式转换。不要把验收清单全部塞进提示词。

| 电影语言 | 可见结果的表达 | 需避免的歧义 |
|---|---|---|
| dolly in / 推轨靠近 | 相机沿直线靠近，近处门框相对背景移动更明显，最终停在面部近景 | 只写 zoom in 可能得到变焦或数字放大 |
| pan / 水平摇摄 | 相机位置保持不变，视线从门转向桌面 | 「向右移动」可能被解释为横移 |
| truck / 横移 | 相机平行桌沿向右移动，前后物体发生视差 | 不能同时要求固定机位 |
| rack focus / 转焦 | 构图稳定，前景钥匙由清晰变模糊，后景眼睛变清晰 | 不能同时要求所有距离始终清晰 |
| negative fill / 负补光 | 人物远离窗的一侧更暗，轮廓仍与背景分离 | 「加一盏黑光」不是清楚的视觉指令 |
| motivated light / 动机光 | 窗侧明亮，背窗面柔和变暗，桌灯只影响附近区域 | 同一场景反打不得凭空换太阳方位 |
| locked shot / 固定镜头 | 起止构图一致，人物在画面内完成动作 | 用正向静止描述；负面栏视模型能力决定 |

## 制作流程

1. **建资产**：建立角色、服装、道具、场景方位和主光参考。只固定真正影响识别与叙事的信息。
2. **做关键帧**：先确认角色长相、手部、关键物件、画面布局与光线；参考图有缺陷时先修图。
3. **先试关键镜头**：优先验证最难、最能决定成败的动作或空间接点，避免批量完成后才发现不可用。
4. **拆运动**：每条生成优先设一个主要视觉任务；模型能稳定处理更长连续行动时，可实测后合并。
5. **保留余量**：区别请求生成长度、实际可用长度和最终入剪长度。对白、动作起落和停顿需要空间。
6. **按剪辑结构生成**：先拿到能讲通故事的必需镜头，再补反应、细节、过渡；首尾帧控制须先核实接口。
7. **逐项修正**：优先改动作或构图中最关键的一个变量，再比较结果；保存输入与输出对应关系。
8. **接片并听声音**：在剪辑时间线上验证眼神、方向、明暗、动作阶段、音频过渡和总长。

复用已有片段制造循环或重复时，按实际动作起止选择素材入点与出点，不假定「前4秒」必然包含完整动作。确认关键接触、完成状态和停顿都在选段内，再分配入剪长度；片尾黑场或标题也计入总长。

Runway 图生视频文档将图像视为主体、构图、光线与风格的起点，文字重点描述运动；还指出源图的缺陷和暗示运动可能影响生成。它提供末帧续接思路，但这不保证连续多次续接没有外观漂移。[A02]

## 镜头卡与提示词

### 镜头卡字段

| 字段 | 原创示例 |
|---|---|
| 镜头ID与成片时长 | S03；最终入剪4秒，生成时长按平台支持选择并预留余量 |
| 剧情作用 | 观众先发现门已被锁，再看人物是否察觉 |
| 输入 | 指定已确认的角色图、场景图或起始帧；没有则标待制作 |
| 起始状态 | 手在门把手下方，门关闭，人物面向画面右侧 |
| 主要动作 | 右手握住门把手，轻压一次，然后停住 |
| 相机 | 固定近景；把手位于画面中部偏上，保留手的运动空间 |
| 光与质感 | 场景窗侧光擦过金属把手，背景保留暗部层次 |
| 结束状态 | 手仍握住把手，门位置未变；下一镜切人物反应 |
| 声音 | 一次机械卡住声；若模型无音频能力，留给后期 |
| 接片约束 | 右手、袖口、把手方向和门的开合状态一致 |
| 验收 | 手未穿过把手、动作只有一次、构图与时长满足入剪 |

### 原创图生视频提示词例

```text
固定近景。画面中的右手握住金属门把手，向下轻压一次后停住。
门保持关闭。手停留在把手上。相机起止构图一致。
```

输入图已承载灯光与角色外观时，先不重复外观长描述。需要新进入的对象或改变光线时再添加信息。

### 原创文生视频提示词例

```text
竖屏近景，老旧车间铁门上的横向金属把手位于画面中部偏上。
一只穿深灰色袖口的右手从画面下方进入，握住把手，轻压一次后停住。
门保持关闭，手停在把手上。相机固定。
场景左侧窄窗投来柔和侧光，金属有可辨识的擦痕，背景较暗。
```

需要英文时翻译动作与空间关系，检查没有增加新的机位、道具或运动；不要声称英文必然优于中文。
音频按平台能力单独处理。Veo 官方指南把对白、音效和环境声作为描述项目；仍须检查台词和口型，提示中的时间点不等于实际精确同步。[A03][A04]

## 连续性台账

逐镜记录会影响下一镜的信息，不为填表虚构细节：

- **身份**：角色ID、服装、发型、配饰；使用同一参考资产版本。
- **空间**：门窗与物件方位、人物位置、轴线侧、进出方向。
- **动作**：哪只手、物件在哪、动作阶段、视线落点。
- **光线**：场景主光来源、方向、软硬和颜色关系，允许随动作合理变化。
- **状态**：门开合、屏幕内容、液体多少、衣物湿度等关键可见状态。
- **接片**：前镜末态、后镜初态及中间是否省略时间。

不要靠简单水平翻转修复所有方向问题：文字、惯用手、主光、服饰和场景地理可能同时翻错。

## 失败诊断

| 失败 | 优先排查 | 最小修改 |
|---|---|---|
| 无意切镜 | 场景跳跃、多个独立任务或时长不够 | 拆镜或只保留一次连续动作 |
| 运镜方向错 | 相机运动与人物运动混写；坐标混用 | 分别写相机路径、人物方向、起止构图 |
| 固定镜头仍漂移 | 源图含速度线或运动模糊；模型惯性 | 改源图、减动作；必要时后期稳定 |
| 多人手脸错位 | 数量、接触和遮挡同时复杂 | 拆正反打与手部镜头，减少交互 |
| 人物每镜变样 | 参考或角色描述变动；续接积累误差 | 回到确认参考重新生成 |
| 反打光位翻转 | 把画面左侧当作场景窗侧 | 写清窗、人物、相机关系，先做反打帧 |
| 剧情文字不可读 | 把精确信息交给生成 | 设计后期替换平面与遮挡，合成准确文字 |
| 漂亮却接不上 | 动作、眼神、道具末态不一致 | 补反应/物件镜头或重做接点 |

## 实拍与生成混合

先列接点：角色、场景延展、屏幕替换、环境或特效元素。根据接点决定空镜、跟踪标记、参考曝光和物件尺寸；不要一律加标记。
保留原片和中间输出，记录色彩转换，避免重复烘焙显示变换。输出规格以项目为准。
对精确文字、手部接触、长对白等难点，比较实拍、合成、拆镜和生成，不默认必须一次生成完成。
