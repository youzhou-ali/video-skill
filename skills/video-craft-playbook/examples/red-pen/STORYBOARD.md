# 《红笔》分镜 v2

## 简报（默认值，待确认）

- 一件事：代码画出来的视频好不好，靠的是"每一帧都被看过一遍"。
- 受众：对"用 Claude 做视频"感兴趣的人；放在博客文章里或发社交平台。
- 时长 30 秒，16:9，1920×1080，30fps。
- 语言：中文，全片只有两处屏幕文字。
- 旁白：不用。当前环境没有可用的 TTS，而且这支片子靠表演就能讲清。
- 音乐与声音：代码合成，120 BPM（每拍 15 帧，每小节 2 秒）。
- 素材：零外部素材，全部代码绘制。

## 角度

写了 10 个，丢掉最先想到的 3 个：流程图讲解"代码→帧→ffmpeg"、屏幕上的代码一行行变成画面、机器人在画布上画画。

留下 3 个：
1. 拧一个标着 t 的旋钮，世界精确地倒放又快进（讲"画面是时间的纯函数"）。
2. 同一个种子开两个世界，两边分毫不差（讲确定性）。
3. 一个小角色跳沟失败，镜头拉开，发现它活在一张被红笔批改的接触表里；改一个数字，再跳一次就过去了（讲审片）。

选 3。它有角色、有失败和逆转、结尾能回到开头的同一个动作，而且讲的正是这个 skill 和其他做法最大的区别：看自己画出来的帧。

## 导演卡

| 项 | 决定 | 理由 |
|---|---|---|
| 梗概与转折 | 墨点想跳过一道水沟，跳短了掉下去。镜头拉开：它的世界是接触表里的一格，一支红笔圈出起跳那一帧，写下"起跳 ×1.4"。格子依次重画，墨点再跳，过去了。 | 转折在 9.5 秒：观众以为在看动画，其实在看审片 |
| 观众悬念 | 0–6 秒：它能跳过去吗？9.5–14 秒：这是哪里？谁在改？ | 两个问题前后接力，中间不留空档 |
| 重点时刻（3 个） | 6.0 秒落水；11.5 秒接触表全貌；21.5 秒落地成功 | 每个停留不少于 1.5 秒，周围画面安静 |
| 主体怎么画 | 墨点：墨色圆身体，直径约占画高 17%（关键帧阶段从 14% 放大，接触表小格里才看得清），两只纸色眼睛，两条短腿。描边 4px，每秒换 12 次种子轻微抖动 | 剪影一眼可读；手绘感来自抖动，不靠滤镜 |
| 可能显得廉价的地方 | 水面和接触表格子。水用三层错开相位的波线，不用平面色块；格子之间留纸色缝和轻微错位（±3px、±0.6°） | 这两处画得太规整，会像幻灯片模板 |
| 色板 | 纸 #F2EBDD、墨 #23201C、土 #C9A86A、水 #3E6E6A、批注红 #D23C2A | 红色只给红笔和批注，观众一看到红就知道"有人在改" |
| 光线 | 平光，无阴影；接触表出现后加一道从左上来的暖色桌面渐变（亮度差 8%） | 世界内是纸面印刷感，拉开后才有"现实"的光 |
| 形式 | 剪辑，共 6 镜；第 1 镜到第 3 镜是同一个跟拍镜头 | 先让观众沉浸在世界里，才有拉开的效果 |
| 镜头运动 | 跟拍横移（慢）；拉远（快，全片唯一的大招）；推入格子（中）；结尾缓慢拉远（慢） | 推拉表示"进入/离开"这个世界，方向和意义一一对应 |
| 节奏 | 镜长 6.0 / 3.5 / 4.5 / 4.0 / 6.0 / 6.0 秒；切点与重击落在拍点 | 不整齐划一，失败后的安静段最长 |
| 转场 | 镜头拉远直接把世界变成一格；推入格子再回到世界（形状匹配）；其余是连续镜头 | 转场本身就是故事，不加装饰性转场 |
| 字体 | Noto Sans CJK SC Medium；批注字 64px、结尾字 72px | 笔迹感靠描边抖动，不另找手写字体 |
| 音乐与声音 | 木块和纸沙锤的轻节拍；脚步、起跳嗖声、落水、滴水、笔划纸、格子重画的嗒声、落地闷响、打勾 | 每个物理动作都有声音；落水后音乐停 1.5 秒 |
| 结尾 | 回到接触表，红笔在角上打勾，一行字"每一帧，都看过一遍"，末帧停 1.5 秒 | 呼应开头的同一次跳跃，结果相反 |
| 后期 | 纸纹叠加（不透明度 6%），不加颗粒、运动模糊和暗角 | 纸纹给质感；颗粒会让文件变大，也和印刷感冲突 |

禁用：粒子爆发、光晕、霓虹、故障效果、处处回弹、重复画面内容的字。

## 母题

- 跳跃：第一次跳短（第 2 镜），第二次跳过（第 5 镜）。
- 红笔：第 3 镜第一次出现画圈，第 4 镜写数字，第 6 镜打勾，一次比一次更"满意"。
- 格子：第 3 镜从世界变成格子，第 5 镜从格子变回世界，第 6 镜所有格子一起亮。

## 情绪弧线

轻快 → 期待 → 失落（安静） → 惊讶（拉开） → 好奇（被改） → 释放（跳过） → 满足。
