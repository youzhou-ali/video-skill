# 《回家的线》交付报告

## 成片

- `回家的线_成片_1080p.mp4`：1920×1080，30fps，900 帧，30.0 秒，H.264 + AAC 320k 48kHz，19 MB
- 响度 −14.0 LUFS；qc.py 的 hook、freeze、pops 全部通过，sceneloud 没有标记
- 源码：`film.html`（画面）、`audio.py`（声音）、`render.cjs`（渲染）；分镜 `STORYBOARD.md`
- 重渲：先在浏览器里导出 `track.json`（`window.nibTrack()`、`window.corners()`、`window.CHAPTERS`），再 `python3 audio.py`，然后 `node render.cjs film.html --audio=audio.wav --out=out/final_raw.mp4`，最后按 SKILL.md 附 C 做两遍 loudnorm

## 风格规格卡

- 风格：一笔画（`vendor/lemo-opuscar/styles/one-line/STYLE.md`），只借语法；故事、画面和代码都是新写的
- 纸 #F4EFE4 加细颗粒和暗角；墨 #1D1A17；唯一强调色暖黄 #E0A030，只给灯泡那一圈；结尾一圈很淡的暖光
- 线：一个点数组，基础宽 3.2 纸面单位 × 笔压（0.66+0.8·e^(−v/300)）× ±8% 噪声；拉远时线宽按 1.3 倍缩放钳住；慢处积墨；终点泪滴墨点
- 时间：按章节时间窗分配，窗内按 1+10×拐角加权；灯泡是全片最慢的一笔
- 镜头：一镜到底，跟随笔尖（−0.55 至 +0.4 秒加权平均），笔尖软约束在画面中间 72%×66%
- 笔：不画笔，只画一道 190px 的影子和接触点
- 声音：由笔速驱动的笔划纸声（快时亮、慢时闷，加纸纤维颗粒声，随笔尖左右声像）；类单簧管独奏，音落在 32 个拐角上，音高跟着笔尖高度走（D 大调五声）；灯泡是最高的长音；线闭合后真正的静音，灯亮时一声钟片

## 两个最弱的时刻

1. **8.5–10 秒的街道和爬墙**：仍然只是一根线在走（qc.py action 0.84）。改法：在街道上加一根路灯杆，揭示时它是屋里的落地灯，近景里也有东西可看。
2. **结尾 3.8 秒**：除了灯光呼吸和缓推，画面基本静止（action 0.24）。改法：把片名改成用一笔画写出来的连笔字，让收尾的动作仍然是"那根线"。需要一款手写体字体，或者自己设计字形路径。
