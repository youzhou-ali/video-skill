# 《回家的线》分镜 v1

风格：一笔画（`vendor/lemo-opuscar/styles/one-line/STYLE.md`）。只借风格语法，不借它演示片的故事、构图和时间。

## 简报（用户授权自定剧本，以下为默认值）

- 一件事：下班路上走过的每一段，合起来就是家。
- 时长 30 秒，16:9，1920×1080，30fps（风格建议 24fps 不抽帧；这里用 skill 默认的 30fps，同样逐帧不抽帧）。
- 旁白：没有。环境里没有 TTS，而且这种风格本来就要少说话，靠线讲。
- 声音：代码合成。一件独奏乐器的单声部旋律，加上由笔速驱动的笔划纸声。
- 素材：零外部素材。字体只有 Noto Sans CJK，没有手写体，结尾字用细体写出来。

## 角度

写了 10 个，丢掉最先想到的 3 个：一个人的一生画成一张脸（就是风格演示片）、河从源头流到海、心电图变成故事。

留下 3 个：
1. 毛线团滚过整个屋子，猫追着线跑，最后整根线是一只睡着的猫。
2. 两根线从两个角相向画来，在中间相遇成一颗心。
3. 一根线从门口出发，坐车、爬上楼、看见屋顶冒烟、点亮一盏灯，最后回到起点。镜头拉开：这一路画的就是房子。

选 3。终点和起点是同一个点（风格里的"循环"结构），回到起点那一刻就是揭示；路上每一段在近景里是一个独立的小场景，在全景里是房子的一部分（风格里的"反向设计"）。

## 导演卡

| 项 | 决定 | 理由 |
|---|---|---|
| 梗概与转折 | 一根线从左下角出发：画出一扇门，变成一列火车，沿街走到尽头，向上爬，沿着斜坡上行经过冒烟的烟囱，到达顶点后垂下一根线，挂起一盏灯，灯泡亮成暖黄色；然后顺着另一侧斜坡下来，落回起点。转折在 22.5 秒：镜头拉开，原来这一路是一座房子的轮廓。 | 观众前 20 秒以为在看通勤路上，最后发现一直在画家 |
| 观众悬念 | 这根线要去哪？ | 镜头始终跟着笔尖，看不到全貌 |
| 重点时刻（3 个） | 15 秒烟囱冒烟（有人在家做饭）；20.5 秒灯泡亮（唯一的颜色）；25.5 秒线回到起点 | 每个停留不少于 1.5 秒 |
| 线怎么画 | 一个点数组从头到尾；墨色 #1D1A17，基础宽 3.2 纸面单位 × 笔压（快细慢粗：0.66+0.8·e^(−v/300)）× ±8% 噪声；慢处积墨；终点停笔成泪滴墨点 | 风格规定 |
| 可能显得廉价的地方 | 火车：只用起伏的方块会像方波。车头做成斜面，车厢之间留间隙，每节车厢顶上一个小圆角 | 近景里要一眼看出是火车，全景里又不能太抢 |
| 色板 | 纸 #F4EFE4，墨 #1D1A17，强调色暖黄 #E0A030 只给灯泡那一圈；结尾灯泡周围一圈很淡的暖光 | 风格只许一个强调色、只用一次；暖光是唯一破例，理由是"灯亮了"就是片子的落点 |
| 形式 | 一镜到底，不剪 | 风格规定 |
| 镜头 | 跟着笔尖走（拖后约 0.55 秒、预判约 0.4 秒）。小场景时放低跟随、构图稳住；最后 4 秒连续拉远到全景 | 一镜里靠跟随权重变化做节奏 |
| 节奏 | 门 3 秒、火车 5.3 秒、街道 2 秒、爬墙 2 秒、斜坡和烟囱 4.5 秒、灯 4.5 秒、回程 3 秒、收尾 4.5 秒 | 不均匀；灯泡那一圈是全片最慢的一笔 |
| 字体 | 结尾两行：Noto Sans CJK SC Light，"回家的线" 56px，"zhongli · 钟笠的个人日志" 28px，从左往右写出 | 没有手写体，用最细的无衬线字体贴近线的气质 |
| 音乐与声音 | 单声部独奏（合成的类单簧管音色），音符落在拐角上；笔划纸声随笔速变化，是最重要的声音；起笔一声木质轻敲；回到起点后音乐停 1 秒，灯亮时一声钟片 | 风格规定"写给线的音乐" |
| 结尾 | 线回到起点，停笔积墨；灯泡亮起；两行字写在房子右下的空白纸上；末帧停 2 秒 | 循环结构的落点 |

禁用：填色、阴影（笔的影子除外）、第二种线宽、背景图、剪辑、第二个强调色。

## 路径（纸面坐标，房子中心在原点）

起点 A(−600, 300) → 地面右行 → 门（宽 100、高 170） → 地面 → 火车（3 节，车头斜面） → 地面到右下角 (600, 300) → 右墙上行到 (600, −50) → 右斜坡上行，烟囱（右缘 x=360，左缘 x=300，顶 y=−330），烟从烟囱顶中点卷上去再原路退回 → 顶点 (0, −420) → 灯绳垂下到 (0, −60) → 灯罩三角 → 灯泡圆（暖黄） → 灯罩 → 沿灯绳退回顶点 → 左斜坡下行到 (−600, −50) → 左墙下行回到 A。

每一段都落在房子的自然线条上，没有多余的连接线；烟和灯绳靠原路退回，退回的线看不出来。

## 草稿阶段的修改

| 来源 | 问题 | 改法 |
|---|---|---|
| 自查全景 | 纸纹的大块斑驳在全景里露出方格和接缝 | 去掉斑驳，只留细颗粒和暗角 |
| qc.py action | 街道和右墙两段直线占 4 秒，只有镜头在动 | 压到 1.5 秒；省下的时间给烟（1.9 秒）和灯泡（2.3 秒，全片最慢的一笔） |
| 陌生观众 | 9–12 秒只见一根线爬升，认不出在画什么 | 镜头拉宽到 z=1.6，让最后一节车厢和墙同框 |
| 陌生观众 | 结尾近 4 秒静止，片名小，声音像掉了 | 片名放大到 72px，居中放在房子下方；结尾三个长音加响；灯光缓慢明暗呼吸，镜头缓推 0.85→0.9。没有采纳"让烟一直飘"：墨迹自己动违背一笔画的前提 |
| 陌生观众 | 笔影像镜头上的污渍 | 影子长度从 560px 缩到 190px，不透明度从 0.15 降到 0.11 |

| qc.py sceneloud | 快速直线段笔声偏尖；回程下坡音符太少显得空 | 高速时降低高频带和音量；回程加 6 个随笔尖下降的音 |
