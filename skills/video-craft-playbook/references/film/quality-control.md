# 诊断与检查

本文件为原创评审流程。只根据实际提供且可查看的素材下结论；把观察、原因假设、修改和验证分开。

## 先确定证据边界

| 输入 | 可以评估 | 不应直接断言 |
|---|---|---|
| 剧本/镜头文字 | 信息、执行条件、时间预算、连续性约束 | 已拍成片的表演和质感 |
| 单帧/参考图 | 构图、光影关系、可见错误 | 完整运镜、真实器材或唯一灯位 |
| 采样帧 | 采到的画面状态和大致变化 | 帧间动作、全片口型或闪烁是否合格 |
| 可播放视频且有声音 | 可见段的节奏、动作、声音、接片 | 未播放段或未提供原素材的完整质量 |
| 原片与参数 | 参数相关诊断、可复现实验 | 现场未记录的真实灯具设置 |

标出时间码、镜头ID或图像位置。若无法查看文件，先说明可进行的是文字方案检查，并索取必要素材，不假装已经观看。

## 优先级

1. **阻止成片成立的问题**：关键剧情看不懂、轴线误用导致对象混淆、关键道具状态不符、台词装不下、源素材不足、对白不可辨、机位物理不可达。
2. **明显损伤表达的问题**：运动无触发、反应被抢切、光源翻转、焦点追错、无意频闪、风噪/衣物摩擦、AI外观漂移。
3. **可选精修**：背景小干扰、微小色差、字幕位置、个别停顿和稳定程度。

此排序是任务管理建议。若用户明确追求实验性的空间断裂、声音遮蔽或失焦，将其与误操作区分，评估是否实现意图。

## 常见症状到最小修复

| 症状 | 证据与可能原因 | 先做的最小修复 | 验证 |
|---|---|---|---|
| 看起来漂亮但不知发生什么 | 镜头都给气氛，缺目标/证据/反应 | 加一条信息镜头或重排已有镜头 | 让未读剧本者描述因果 |
| 运镜像飘来飘去 | 启停与人物行动无关 | 固定起止点，删除一段不提供信息的移动 | 静态版与运动版比较 |
| 画面像平面背景 | 人物贴墙、明度相近、无空间层次 | 调位置、背景或控光中的一项 | 同机位前后对比 |
| 暗戏只剩黑和噪点 | 关键表演缺少可用曝光 | 增加局部光或改变站位，再定最终黑位 | 经目标输出转换后看片 |
| 高光全保住但人物不可读 | 曝光优先级与剧情不符 | 给人物补足光或简化背景 | 关键表演和背景同时复核 |
| 两人像不在对话 | 视线、机位高度或景别关系不一致 | 以共同空间参照重做一侧 | 连播主镜与两个反打 |
| 反打光线不在同一世界 | 光源跟着画面左右移动 | 按场景窗位修正，保留必要的面部修饰 | 在时间线上看切换 |
| 动作跳跃 | 使用不同动作阶段接片 | 找重叠动作或补反应/细节 | 看完整动作因果 |
| 台词与情绪过急 | 固定短镜头塞过多台词 | 实际朗读后删词、加时或减少镜头 | 用表演节奏读而非快速念完 |
| 手机自动亮度/颜色变动 | 自动参数随构图变化 | 支持时锁定，或缩短动作/机位变化 | 原文件连续回放 |
| 单镜合格但整片拖 | 镜头任务重复、停顿无变化 | 删除重复信息，保留关键反应时间 | 无音乐版也能理解节奏 |
| AI手、道具、数字不稳 | 交互复杂或精确信息依赖生成 | 拆镜、用真实道具或后期合成 | 检查每个影响剧情的状态 |
| 声音一切镜就换房间 | 环境底噪/混响不连贯 | 用合适环境底声和交叉过渡衔接 | 闭眼听接点 |

## 逐镜检查

- 写出镜头的任务；没有任务时尝试删除或合并，不为凑镜头数保留。
- 核对角色、视线、手、道具、进出方向和时间推进。
- 核对运动起止、焦点、画面边缘、反光和连续光区。
- 给关键台词、动作、证据和反应足够观看时间。
- 确认现场条件或模型能力能实现计划；不把希望当验收结果。
- 看完整时间线中的前一镜和后一镜；不要只挑单帧判成功。

## 时长数据与检查器

使用 `assets/shot-plan-template.json` 的字段；镜头数组按剪辑顺序排列。

| 字段 | 含义 |
|---|---|
| `target_duration_s` | 成片目标秒数，或 `[最短, 最长]` 范围；必须为正 |
| `fps` | 项目时间线帧率，可省略；用于默认一帧容差，不代表拍摄帧率 |
| `shot_id` / `duration_s` | 唯一镜头ID及该片段在时间线上的长度 |
| `transition_out_s` | 与下一镜的画面重叠秒数；硬切填0，最后一镜必须0 |
| `handle_in_s` / `handle_out_s` | 未计入该片段的首尾剪辑余量，按时间线播放速度折算 |
| `usable_source_s` | 素材按时间线速度解释后的可用长度；尚未拍/生成用null |
| `purpose` / `camera` / `audio` | 文字任务、机位运动与声音描述；缺少时提示补充，不冒充艺术评审 |

检查器计算：`成片长度 = 各片段长度之和 − 相邻画面转场重叠之和`。
它核对重复编号、非法数值、片长目标、相邻转场和素材余量；限制为顺序镜头和两镜间转场，不模拟多轨叠加、分屏或嵌套序列。复杂剪辑以编辑软件时间线为准。
旁白和音乐跨镜不减画面长度。50fps素材若按25fps逐帧播放，其解释后长度与实时播放不同，先换算再填 `usable_source_s`。
使用 `python3 scripts/check_shot_plan.py plan.json --json` 获取结构化结果；有硬错误退出码1，格式/读取错误退出码2，只有提醒时仍返回0。

## 完成标准

交付时说明：已经完成的设计、实际完成的检查、尚待实拍或生成验证的事项。
每条修改给具体位置和方法，优先解决一个根因而不是同时改光线、构图、机位、表演和剪辑。
当相关问题已解决且没有新的具体风险时停止追加检查；不反复把创作差异当错误纠正。
