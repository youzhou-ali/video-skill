## 先锁定记录与交付条件

先确定：机型/记录模式、镜头/滤镜、拍摄帧率、时间线帧率、快门、分辨率/裁切、编码/位深、伽马/色域、白平衡、监看变换、SDR/HDR及交付平台。
未知时用条件分支，不能把“RAW”“Log”“10-bit”“HDR”混当同一属性。
在镜头表里区分拍摄帧率与播放帧率；慢动作是否需要同期对白必须预先决定。
需要多机位匹配时，首先统一可控参数并拍参考，不仅要求型号一致。

## 曝光控制的分工

| 控制项 | 主要创作任务 | 调整时保留的约束 |
|---|---|---|
| 现场光量/方向 | 保证信息与空间层次，改变信噪条件 | 演员走位、反差、实景动机、收音 |
| 光圈 | 决定可接受的景深与焦点容错，同时影响曝光 | 镜头实际表现、全程合焦需求 |
| 快门/曝光时间 | 选择运动模糊，兼顾频闪 | 不为临时调亮而无记录地改变动作质感 |
| ND | 在较亮环境保留所需光圈与快门 | 检查偏色、反光、可变ND交叉纹及滤镜组合 |
| ISO/增益/基准档位 | 按具体机型决定记录和噪声行为 | 不能一概认定调ISO只改亮度或只改元数据 |
| EI | 在支持的模式中指导曝光和监看 | 与真实进光量、基准ISO区分，见下文 |

先保证需要的动作模糊和景深，再用光、ND及适合的记录档位实现曝光。不要把调整某个按钮当作能替代现场光量。
镜前均匀ND同时降低整个画面的进光，不能缩小窗外与室内的现场亮度差；若差值超出可用范围，需改变局部光、时间、位置或构图。
镜面高光、灯泡核心、天空和脸不是同一种保护对象；按故事决定哪部分必须保留纹理。不要为了保住无关灯丝，把关键表演压进不可接受噪声。

## 监看与肤色判断

明确每个仪表在测什么信号：原始Log、已加技术转换的输出、创意Look之后，或显示器自己的处理之后。不同阶段读数不可直接互换。
检查视频/数据电平解释，避免范围错配导致黑位、白位和假色判断错误。

| 工具 | 用途 | 常见误用 |
|---|---|---|
| 波形 | 定位脸、窗、服装等画面区域的信号水平 | 把画面平均值当作主体曝光 |
| RGB parade | 看通道失衡与单通道剪切 | 只看亮度波形而遗漏红/蓝通道问题 |
| 斑马纹 | 快速检查已定义阈值 | 未确认伽马和信号阶段就复制别人的阈值 |
| 假色 | 按具体设备图例定位曝光区域 | 把颜色名称当跨品牌通用肤色目标 |
| 直方图 | 粗看信号分布与两端堆积 | 认为靠左必然欠曝、靠右必然正确 |
| 矢量示波器 | 检查色彩方向和饱和度 | 强行把所有人物肤色推到一条固定线上 |

ARRI 的假色规范区分机型、Log版本和EI相关区域；外接监视器必须匹配实际输入及其假色实现。[L10]
以实际演员、妆发、服装、关键材质试拍，判断表情、皮肤层次和背景关系；肤色深浅与创意意图不同，不能规定“所有脸都是70 IRE”。
当数值与肉眼观感冲突时，先核对信号链和显示环境，再改曝光。

## Log、ISO与EI

Log是编码方式，不会自动挽救已经剪切的高光或缺失的暗部信息。先确定对应伽马和色域，再选择正确转换；不要把低反差预览误认为最终外观。
Sony 的创作者指南给出 S-Log3 中18%反射灰的基准信号约41%；这是特定编码的灰卡基准，不是所有肤色目标，也不是任意监看LUT之后的数值。[L08]

**不默认“Log统一加两挡”。** 需要更干净暗部时，允许在保护关键高光的前提下测试增加实拍曝光；用后期还原后的噪声、色彩与高光评估，不凭取景器看起来更亮决定。
未知机型时不要猜双原生ISO或第二基准档位，更不能用其他机型的数字填表。

Sony 对 Cine EI 的说明中，记录ISO对应所选基准ISO，改变EI主要改变监看与曝光指导；若降低EI后按照监看重新增加进光，才改变实际传感器曝光。此行为不能推广到所有“ISO”菜单或其他品牌。[L09]

| 情况 | 行动 |
|---|---|
| 暗部噪声高、关键高光仍有余量 | 比较增加现场光/实际曝光后的后期匹配结果 |
| 窗外信息重要、脸太暗 | 调整场地/时间/布光与构图；单降整体曝光会一起压暗脸 |
| 换了ISO但RAW未按预期变亮 | 核对是否仅EI/元数据变化、基准档位和解码设置 |
| 同一曝光套不同LUT差异很大 | 核对输入伽马/色域、转换顺序及LUT用途 |
| 只有8-bit且交付很急 | 评估适当机内外观和较温和后期；不因“电影感”强制Log |

## 色温、混光和灯光光谱

先选择主导光源和想保留的冷暖关系，再设置并记录白平衡；固定机位对话不默认让自动白平衡随构图漂移。
色温控制与绿/品红偏色是不同轴；灰卡在无创意变换时可帮助检查中性，RGB波形或矢量示波器可辅助观察。[L11]

若相机按某主导灯光设中性，其他光源可有意偏暖或偏冷。示例：“人物主光接近日光，背景台灯保持温暖”比不带条件地写“全部5600K”更可执行。
同标称色温不保证同样显色。Academy 的SSI说明强调灯光光谱与摄影机响应的关系；SSI比较的是指定参考光谱相似度，CRI或单个分数不能代替实拍测试。[L07]

混光排错顺序：

1. 逐个开关光源，找出产生异常肤色的贡献。
2. 处理不想要的实景光：关灯、遮挡、换位或换已测试光源。
3. 按设备能力调色温与绿/品红；记录胶片/滤色片或灯具设置。
4. 同时拍灰卡、色卡、皮肤和关键服装，查看目标输出下的结果。
5. 若混色是创作意图，记录哪些区域允许偏色，不把整个画面强制拉白。

## 50Hz环境与频闪测试

中国大陆常见50Hz供电场景可从适合项目的25fps/1⁄50s或50fps/1⁄100s开始试拍；这只是测试起点。项目已定24fps时，不擅改时间线，可测试1⁄50s等曝光时间并评估动作模糊。Sony 拍摄指南列出的50Hz参考快门为1⁄50或1⁄100s。[L12]

LED驱动、调光、显示屏刷新及摄影机读出可能引入不同频率。Sony 的机型指南区分照片防闪与可变快门，并要求检查实际记录；不能假设开“防频闪”就对视频有效。[L13]
ARRI SkyPanel FAQ展示了高速模式、调光和频率选项之间的器材特定限制；不要把某灯具的无闪宣传推广到所有灯、所有亮度和所有帧率。[L14]

频闪验证流程：

1. 用最终相机模式、分辨率、帧率、快门拍摄实际灯具与屏幕。
2. 覆盖计划使用的调光亮度与动态灯效，不只测100%亮度。
3. 录一段静止画面及所需运动；回放原文件，检查呼吸式亮度变化、横带、色带。
4. 一次改一个变量：快门微调、灯具频率/模式、屏幕刷新、调光方式或替换光源。
5. 重拍并确认运动模糊、曝光和屏幕内容仍合要求；记录成功组合。
6. 快速替代：关掉问题灯、换可靠灯或改变构图；后期去闪仅作补救选择。

手机慢动作可帮助发现问题，但其相机时序与正式摄影机不同，不能作为最终合格证明。

## 色彩管理和交付

使用能解释的链路：**正确解释素材 → 统一工作空间 → 校正与创意调整 → 针对目标显示的输出转换 → 导出复核**。
ACES输入转换把摄影机原生数据转入其场景参照体系；输出转换按目标显示与观看条件把场景参照数据变成可显示状态。这是管理方法，不是自动“电影滤镜”。[L15][L16]

对单机小项目，可使用软件管理流程或正确的官方技术转换；无需为显得专业而强制引入完整ACES。
明确“技术转换LUT”和“创意Look”的输入、输出以及插入位置。避免自动色彩管理已经转换一次，再叠第二次Log→709转换。
ARRI 文档区分LogC3与LogC4及相应Look流程；旧Look不能仅凭文件名套到新编码，需正确转换或重新匹配。[L11]

交付前至少检查：

- 目标是SDR还是HDR，色彩标签、伽马和电平解释是否一致。
- 镜头之间的肤色、黑位、主要光色与反差是否连续。
- 饱和灯光是否单通道剪切，暗部是否因压缩出现色块，渐变是否断层。
- 字幕、图形、片尾和外部素材是否经过正确解释，且在目标画幅内可读。
- 导出文件重新导入并在目标播放环境复核；记录环境差异，不用一个播放器的显示替代全部判断。

## 测试卡与排错

```text
机型/固件/记录模式；帧率/快门；镜头/光圈/ND：
ISO或基准档位；EI；白平衡/偏色：
伽马/色域/位深/编码；监看变换与仪表所在信号阶段：
演员与关键材质；关键高光/暗部必须保留什么：
灯具/调光/频率；频闪测试结果：
曝光测试A/B/C；统一还原后的噪声/肤色/高光比较：
工作空间；输出转换；目标显示与导出参数：
选用设置、理由、仍需确认的事项：
```

遇到不可确认的设备行为，明确缺少哪项资料，先给可进行的试拍；不捏造动态范围、IRE阈值、基准ISO或硬件控制能力。
